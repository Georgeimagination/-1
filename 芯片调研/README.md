# 芯片调研

这里集中保存具体芯片产品的原始资料、资料卡、产品详解和比较分析。正式比较单位采用具体 SKU（硬件配置明确的产品型号）或官方单芯片配置，完整口径见[调研计划](../调研计划.md)。[前置调研](../前置调研/README.md)提供负载特点和架构关注点，产品事实在本目录按来源分别记录。

阅读产品介绍可直接打开[图文阅读版](产品详解/产品详解-阅读版.html)。其中的[全产品比较](产品详解/产品详解-阅读版.html#comparison)为汇总报告第一层，覆盖 36 个产品并提供 8 张比较图。

| 内容 | 用途与入口 |
|---|---|
| [原始资料](原始资料/) | 论文、网页快照和来源清单；[资料总览](原始资料/参考资料总览.md)记录资料池的来源，[参考资料压缩说明](原始资料/参考资料压缩.md)解释资料筛选过程。 |
| [资料卡](资料卡/型号索引.md) | 产品规格和共享架构的事实记录；[参考资料索引](资料卡/参考资料索引.md)用于查找各产品使用的来源。 |
| [产品详解](产品详解/README.md) | 按厂商阅读产品文章、架构图和规格说明。 |
| [比较分析](比较分析/训练与推理架构比较.md) | 第一层全产品比较报告及绘图数据；[比较维度与数据支持范围](比较分析/比较维度与数据支持范围.md)保留前期分析项盘点。 |

产品范围和原资料卡状态见[待调研芯片清单](../待调研芯片清单.md)，最新进展和下一步见[进度记录](../进度记录.md)。早期比较报告保存在[历史比较分析](../99_归档/02_主线旧流程/历史比较分析/)，历次核查记录保存在[核查记录](../99_归档/02_主线旧流程/核查记录/)，按记录日期追溯。
