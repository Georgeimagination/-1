# 两层比较的维度与数据范围

2026 年 9 月 23 日确定。范围为现有 7 家厂商、36 个产品；本文说明主报告实际采用的比较问题及未进入统一数值图的原因。第一层先按官方主要目标分类，再观察指标；官方支持用途另列。第二层使用同家族官方资料解释资源和机制变化。

## 第一层确定的比较内容

| 比较问题 | 呈现方式 | 数据与条件 |
|---|---|---|
| 数值格式支持 | 全产品能力矩阵 | 36 产品，原生、转换条件、明确不支持、冲突和未知分别记录；不能按支持格式数量打分 |
| 同精度计算规模 | 16 位峰值主图；FP8、FP4 分面补充主图 | 16 位、FP8、FP4 分开，dense 与条件项分开；产品规格和软件性能模型不混用 |
| DRAM 容量与带宽 | 两个绝对量面板 | 各 33 个产品有选定值；Groq 的片上主存路线独立说明 |
| DRAM 与算力配比 | P-B、P-C 散点及比值图 | 16 位为 27 个可配对对象；低精度仅使用同配置、同路径可配对记录；C/P 与 B/P 不代表实测性能 |
| 设备互联及与计算的配比 | 端点带宽、D/P 两面板 | 22 个产品的选定端点方向和范围明确；PCIe 主机接口不混入专用设备互联 |
| 功率规格 | 芯片、板卡、模组分面 | 18 个边界明确记录；额定上限不作为负载耗电 |
| 定位差异是否重复出现 | 同厂商分布及敏感性表 | 明确矩阵子集、厂商值条件子集分别判断，报告每组有效产品数与家族数；单一家族多个 SKU 不作独立重复证据 |

低精度图覆盖 FP8 家族 21 个、FP4 家族 8 个产品。它们不是条件完全相同的集合：MX 格式、转换输入、未展开 dense 条件和 TPU 8 精度来源分歧必须显式标记，逐项条件与来源随绘图数据保留。AWS 的新增值沿用纯 TensorEngine 口径，不与整芯片宣传值混配。TPU 8 的 JAX 静态成本模型仅作开发模型补充，不补造缺失的 16 位产品峰值。

## 补充表及只在家族内展开的内容

| 内容 | 处理与边界 |
|---|---|
| C/B、D/B | 保留全产品补充表。前者是按标称带宽流过完整容量的理想时间，不是随机访存延迟；后者是接口预算比，不是实际通信占比 |
| 同产品低精度吞吐倍率 | 同一路径、同配置且稀疏条件一致时计算；不能从位宽比例反推硬件峰值 |
| 稀疏支持与条件 | 逐产品补充事实表；结构化模式、专用 SparseCore 和软件跳零不等同，不统一成稀疏加速分数 |
| 主机接口 | 记录协议、代际、宽度与原文方向；不拿协议上限替代实测或未公开的设备端点带宽 |
| P/W | 仅在 16 位峰值和功率边界匹配的子集中列配置比值；不同供电边界分开，不给实测能效排名 |
| 存储组织、介质与部署 | 统一分类与文字解释，作为数值分布的背景；cache、scratchpad 与部分和缓冲不能相加为等效 L2 |
| L2、每核局部存储、片上带宽、阵列与搬运机制 | 第二层按实际作用域展开；某方未披露不等于没有该机制 |

B/P 与 P/B 是同一信息的倒数，C/P 又由 C/B 与 B/P 相乘得到，不能把它们视为相互独立的三份统计证据。模型容量、batch、上下文和实测吞吐不作为芯片属性；本轮不新增硬件 benchmark。

## 第二层产品组与资料卡补充

按已确认计划，依次研究 TPU 8t/8i、Ascend 950PR/DT、Trainium1/Inferentia2；TPU v5e/v5p、H100 三种形态、MI350 家族；H200 两种形态、L4/L40S、Atlas 300I A2 两容量；H100→H200 两分支、MI300X→MI325X、Trainium2→Trainium3。前三组直接研究负载定位分化，其余按部署、规模和代际因素分别解释，不预设都存在训练与推理的核心差异。

每组由一名代理直接阅读官方资料，自主发现有价值的维度。发现资料卡遗漏的可靠事实就补回资料卡，包括只能确认一侧、暂时不能配对的内容；主会话核对后合并到对应字段或章节。已确认新增事实不能只留在临时摘录或比较报告中。
