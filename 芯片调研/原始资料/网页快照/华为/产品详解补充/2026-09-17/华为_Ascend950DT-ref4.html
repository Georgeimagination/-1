Atlas 650E

Atlas 650E

The Atlas 650E server, powered by eight 950DT NPUs, delivers up to 12.4 PFLOPS @ mxFP4. It features Huawei’s self-developed on-chip memory with up to 4.0 TB/s R/W bandwidth while supporting 16-NPU full-mesh via UnifiedBus Link 2.0 protocol. Designed for standard air-cooled data centers, it offers efficient, reliable AI computing for industries such as finance, government, healthcare, etc.

Product Features

MXFP4 Low-precision Inference
  • Achieve industry-leading compute performance of 12.4 PFLOPS @ mxFP4
  • Support HiF8 / mxFP8 / mxFP4 data formats，significantly improving quantization acceleration performance
Ultra-high Memory Bandwidth
  • Deliver industry-leading memory R/W bandwidth of 4.0 TB/s
  • 768 GB on-chip memory per server
Ultra-high UB Link Bandwidth
  • Provide 13.4 TB/s UB Link bandwidth per server (16-NPU FM)
  • Support 16-NPU UB full-mesh interconnect across 2 servers
