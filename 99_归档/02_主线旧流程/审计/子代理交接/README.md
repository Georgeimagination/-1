# 子代理交接说明

本目录保存可以脱离聊天上下文复核的子任务记录。每个子任务使用一个独立 Markdown 文件，文件名优先采用任务编号或稳定的任务名。子代理只修改自己的交接文件；全局台账、当前状态、里程碑、字段字典和共享 CSV 由主代理统一维护。

交接文件按以下顺序书写：

## 任务状态

写明 `进行中`、`待总控验收` 或 `受阻`。子代理不能自行把全局任务标成 `completed`。

## 输入

列出实际读取的本地文件、目录、网页和任务边界。网页注明访问日期；没有读取正文的入口不能写成已用证据。

## 已完成

说明实际处理的对象、形成的结论和产物。规格事实要带对象层级、条件和原文定位；筛选结论要写独有贡献或覆盖关系。

## 验证

记录已经执行的文件检查、数量核对、主键检查、原文回查或其他验证，并保留可以重复执行的输入与结果摘要。

## 未解决

只写仍需总控判断、需要补证据或存在冲突的问题。把 `未公开`、`未找到`、`不适用` 和 `待验证` 分开。

## 建议下一步

给出接手者可以直接执行的后续动作，并说明依赖条件。不要把尚未完成的建议写入“已完成”。

## 写入文件

列出本任务实际创建或修改的全部路径。没有落盘文件的结论不视为可交接成果。
