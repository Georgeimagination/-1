# 来源覆盖与筛选建议

本包按“一个来源是否为选定事实集合提供不可替代信息”筛选，不按厂商、媒体或论文的名义等级机械入选。来源原件都保留；`redundant_covered` 只表示它对本包已经选定的事实没有新增内容，不表示整份文档永久无用。

## Groq 第一代

ISCA 2020 论文是第一代 TSP 架构、数值路径、显式 SRAM 与 C2C 机制的主来源。GroqChip Product Brief v1.7 提供后续产品修订和程序员可见格式，不能被 2020 论文替代；两份都建议进入相应物理对象或架构卡的来源池。2019 白皮书没有取得正文，不能判为已被覆盖，只能标 `inaccessible`。ISCA 2022 scale-out 论文的 ACM DOI 当前为 HTTP 403，Groq 官方地区 PDF 镜像为 HTTP 522；正文仍不可用，因此只保留原子端点和检索记录。

## NVIDIA Groq 3

架构博客覆盖本包需要的执行路径、SRAM-first 管理、确定性编排和 C2C 基本机制。C2C 专题博客补充 high-radix point-to-point、编译期路由与 plesiosynchronous 时序，存在独有信息，建议保留。LPX 产品页对本包选定的架构事实由架构博客完全覆盖，因此建议 `redundant_covered`，覆盖范围严格限定为 `selected_fact_set`；产品状态、商业交付等未来问题仍可用这个快照。

## 华为 Da Vinci

Hot Chips 2019 与 HPCA 2021 不能互相替代。前者直接支撑初代名称、组件和存储层级，并为图中的具体容量保留实现线索；后者补充共享核心机制、数值路径和 MTE，也为典型 cube、Ascend-Max 吞吐与带宽保留配置线索。所有具体配置都进入 `implementation-object-backlog.csv`，不再作为初代架构事实。

## 寒武纪

MLUarch05 名称和思元590关系复用正式库现有 WAIC 来源；`mtp_592` / `__BANG_ARCH__=592` 复用正式库现有 MLU-OPS 固定提交，不重复建 source 或 fact。思元370页面仅用于说明物理架构名是 MLUarch03，从而阻止 BANG v3 与物理架构默认合并。思元290-M5 页面只确认产品身份，作为 v2 线索。CNToolkit 3.8.4 正文远端 HTTP 401，不能用搜索摘要生成事实。

## 媒体边界

本包没有把媒体报道放进正式事实链。后续若媒体包含无法从一手来源取得的原始测量、拆解或直接采访，可以单独作为验证候选；单纯复述厂商白皮书、产品页或新闻稿的报道不进入最小集。
