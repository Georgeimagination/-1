## 异常记录

第一次独立聚合探针调用了当前 .NET 运行时不支持的 `System.Convert.ToHexString`；随后改用 `BitConverter.ToString` 重算并匹配冻结聚合。第一次正向镜像放在过深目录，Windows 路径长度使一份 HTML 快照复制失败；事务按设计回滚，改用同一独立复核目录的临时短路径后重跑通过。另有一条复核辅助脚本曾以 UTF-8 无 BOM 保存，Windows PowerShell 5.1 对中文字面量解码错误；改为 UTF-8 BOM 后通过。数组逆序辅助函数曾原地修改源数组，使复核摘要中的布尔值误记为假。改用独立逆序副本后，依据原始事务日志重新验证为真。生成复核清单聚合时还有一次 `Where-Object` 比较语法写错，第一次摘要因此得到空集哈希；清单本体没有出错，改用脚本块比较后确认 30 个成员并重写了摘要。

这些问题分别属于模型操作失误或复核辅助实现错误，没有发生用户拒绝、自动审批拒绝、审批连接失败、沙箱拒绝或远端服务错误。正式写入次数为 0，复核结果没有因此降低验证范围。
