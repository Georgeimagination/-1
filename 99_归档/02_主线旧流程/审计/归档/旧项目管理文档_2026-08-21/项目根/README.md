# 训练与推理芯片调研

本目录包含两项相互衔接、证据边界不同的调研。前置专题先回答“研究训练与推理芯片时应关注哪些架构问题”；主线资料库再回答“49 款芯片分别有哪些可核验事实，最少需要保留哪些参考资料”。

## 两个入口

| 目录 | 适合阅读的内容 |
|---|---|
| [01_前置调研-训练推理架构关注点](01_前置调研-训练推理架构关注点/README.md) | 19 份固定语料、逐篇分析、总结报告、分析模板和专题核验 |
| [02_主线调研-49款芯片资料库](02_主线调研-49款芯片资料库/README.md) | 49 款冻结芯片、原始资料池、规范事实、来源筛选、最小参考资料库和一芯片一文档 |

前置专题的结论用于确定研究问题，不自动写入正式事实库。主线资料库中的数字必须回到具体对象、条件和来源，也不能因为专题报告给出了概括性判断就跳过逐芯片核验。

## 恢复工作

继续前置专题时，从第一个目录的 README、语料清单和证据矩阵开始。继续资料收集、来源过滤、最小来源选择或逐芯片建档时，先进入第二个目录，阅读其中的 `AGENTS.md`、冻结芯片名单、决策记录和当前状态。

主线数据清洗的运行根是 `02_主线调研-49款芯片资料库/`。`论文/`、`清单/`、`数据/`、`最小参考资料库/` 和 `scripts/` 仍保持原来的相对关系；正式表和来源入口中的本地路径继续相对于该运行根解析。

目录迁移的路径映射、内容基线和验收结果保存在[迁移验收记录](02_主线调研-49款芯片资料库/审计/目录迁移验收_2026-08-18.md)。
