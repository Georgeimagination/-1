# 长任务记录说明

`进度/` 保存跨会话继续工作所需的最小状态。聊天记录不是任务状态的唯一来源。

芯片研究范围单独维护在 `清单/训练与推理芯片名单.md`。进度文件只记录阶段和执行状态，不复制第二份芯片名单。

| 文件 | 责任 |
|---|---|
| `当前状态.md` | 唯一的当前停点：正在做什么、完成到哪里、下一步和阻塞 |
| `任务台账.csv` | 每个任务的负责人、状态、输入、输出和验证结果 |
| `里程碑.md` | 各阶段进入和退出条件 |
| `决策记录.md` | 会影响范围、字段、证据或工作方式的持久决定 |

子 agent 的详细交接文件保存在 `审计/子代理交接/`。总控验收交接后，把结果摘要写回当前状态和任务台账；未验收的子 agent 结论不进入“已完成”。

状态更新规则：

1. 启动任务时，在 `任务台账.csv` 中登记 `in_progress`。
2. 产生可复核成果后，记录输出路径和验证证据。
3. 只有验收通过的任务才能标为 `completed`。
4. 每个工作节点结束前更新 `当前状态.md`。
5. 影响后续工作的选择写入 `决策记录.md`，不只留在聊天中。
6. 阶段门通过后更新 `里程碑.md`、README 和 AGENTS 中的当前状态。
