## 3. 一句话定位、作者主张与机制

**一句话定位：** 这篇综述把“训练计算量大、推理受时延和功耗约束”进一步映射到部署位置，主张云端 GPU/ASIC 更适合训练，而边缘 FPGA/ASIC 更适合推理，同时以云—雾—露协同否定绝对的训练芯片/推理芯片二分。

[原文事实] 作者在 L70 将训练描述为比推理更计算密集，在 L70–L72 将推理描述为常受单样本亚秒级时延限制；L103 又把云端训练评价重点归为承载大工作负载的计算能力，把推理重点归为功耗。L218–L223 则把端侧有限功耗与低精度、稀疏、专用化和本地处理联系起来。上述判断是作者的综述主张，不是本文自行测得的结果。

[原文事实] 文章给出的主因果链是：**训练大规模并行计算和数据量较大 → 系统首先追求计算能力、扩展性与训练速度 → 云端采用多核/众核 GPU 或 ASIC，并借助混合精度和 Tensor Core 提高训练吞吐**（L70–L73、L103–L108、L148–L183）。另一条链是：**实时推理要压低网络往返时延且端侧功耗受限 → 系统追求本地响应和每瓦性能 → 推理向露/边缘部署，并使用低精度、稀疏、FPGA 或 ASIC**（L206–L223）。

[分析者推断] 这两条链首先解释的是“部署条件导致的体系结构取舍”，并非证明存在两类互斥的芯片。文章本身在 L251 建议训练留在云端、推理分布于雾/露端，L183 还允许一个数据流图同时映射到 CPU、GPU 和 ASIC；同一 GPU/ASIC 类别也被用于训练和推理。因此，更可靠的表述是“工作负载目标改变资源配比和部署”，而不是“某种硬件类别天然只属于训练或推理”。

关键断言的证据结构如下：

1. **主张：训练倾向云端高并行平台。** 证据是训练更计算密集（L70），云端训练评价重点是计算能力（L103–L104），作者最终把 GPU/ASIC 视为云端训练的优选（L250）。条件是 2019 年 CNN/DNN 大工作负载；限制是叙述性综述，并未把训练时间到目标精度或分布式通信统一量化。
2. **主张：端侧推理优先时延和能效。** 证据是本地处理避免云端网络往返（L206），端侧受功耗限制（L218–L223），表 7显示 Tegra X1 在较低绝对吞吐下有较高 img/s/W。条件是 AlexNet 等 CNN、IoT/WSN 端设备；限制是厂商转引数据和缺失测试条件。
3. **主张：低精度与专用化可改善资源受限推理。** 证据是 L219–L223 对低精度、稀疏、INT4 和 QNN 的讨论以及表 4。条件是二值/量化 DNN；限制是内核数据与端到端推理混杂，不能迁移成现代 LLM 解码的定量结论。
4. **主张：异构性能数字不能直接横比。** 证据是作者在 L101 的明确方法警告，且表 2–表 8的来源、网络、精度、批量、对象层级各不相同。这个限制应优先于表格中的平台排名。

## 7. 跨图表推理与反例

[分析者推断] 表 2与表 7共同说明“最快”和“最省电”不是同一个目标：表 7中 Core i7 的吞吐高于 Tegra X1，但 Tegra 的每瓦性能约为前者 6.6 倍；若部署从云端移到露端，功耗目标可能改变架构选择。替代解释是两者精度和测试平台不同，因此不能把差异完全归因于芯片架构。

[分析者推断] 表 5在小 batch 下 V100 更快、在 batch 1024 时两者接近且 TPUv2略高，说明利用率和批量会改变相对结果。它支持“条件化比较”，不支持“某架构始终更适合训练”。替代解释还包括软件版本、输入流水线和系统互联，原文均未控制。

[分析者推断] 表 3和表 4表明降低精度会改变可实现的算力与能效，但表 4没有把训练和推理拆开，也没有统一的端到端模型结果。因而这只能支持“数值格式是架构效率的重要条件”，不能单凭 1 bit 吞吐给芯片贴推理标签。

文章提供了两个反例。第一，同一 GPU 和 ASIC 类别可同时服务训练与推理（L103–L121），平台类别不是用途标签。第二，作者主张云—雾—露混合部署：训练在云端，推理可在雾/露端，预处理和更新在雾端（L251–L256）；这是一种按阶段组合系统，而不是两类互斥芯片。L183 所述 CPU、GPU、ASIC 跨机器映射又进一步支持异构组合。

## 8. 适用时代、工作负载与缺失项

这篇文章属于 2019 年 CNN/DNN、物联网（IoT）和无线传感器网络（WSN）语境。AlexNet、VGG、ResNet-50、ImageNet、二值网络和神经形态芯片占主要篇幅；“云、雾、露”是部署分类核心。可迁移到现代 LLM 的，是两条机制：训练的大规模并行与系统扩展需求会提高对算力和通信的重视；低时延、低功耗、本地化推理会推动低精度、专用化和能效优化。不能直接迁移的，是表中各平台排名、CNN 的 img/s 数字，以及“端侧推理”对数据中心逐词解码的替代解释。

主要缺失项包括：训练的梯度、优化器和激活状态；推理的权重常驻、KV cache、前缀缓存和并发；HBM 容量与带宽；同口径峰值算力；机器平衡点与算术强度；集合通信与互联拓扑；服务质量、尾延迟和成本；LLM 预填充、解码、长上下文和 MoE。文章也没有统一重跑表 2–表 8，作者已在 L101 明确说明异构测试条件和 DNN 设计阻碍直接比较。
