# 芯片训练与推理差异分析模板

> 版本：0.1  
> 一次填写对象：一个芯片或一个封装；不能把卡、服务器、机架或集群参数直接填进来  
> 证据截止日：`YYYY-MM-DD`  
> 填写人/复核人：`待填` / `待填`

## 先定对象，再填数字

这份模板用来回答一个有限问题：在公开资料允许的范围内，这个芯片或封装为什么更适合某些训练、预填充或逐词解码条件？它不预设“训练芯片”和“推理芯片”是两个互斥类别，也不允许只凭一个峰值或比值下结论。

服务器、加速卡、云实例、机架、集群和软件可以作为外部对象引用，但必须给出独立对象名和关系。来源只披露系统聚合值时，应把该值留在系统对象，不得除以芯片数后伪装成单芯片事实，除非原文明确允许且计算假设完整。

## 派生指标：先核口径，再计算

在计算前逐项确认：分子和分母属于同一对象；使用同一精度路径；稠密与稀疏没有混用；峰值与实测没有混用；带宽方向与单位已统一；工作负载状态的作用域与设备容量一致。任一项不满足，就把派生值记为 `not_comparable` 并说明原因。

### 12. 机器平衡点

$$
R_{P/B}=\frac{P_\text{peak}}{B_\text{HBM}}
$$

单位为 FLOP/byte（整数路径用 OP/byte）。它表示给定计算路径相对HBM带宽的机器平衡点。只有再拿同一口径的工作负载算术强度与之比较，才可讨论计算受限或带宽受限。

| 字段 | 值 |
| --- | --- |
| $P_\text{peak}$ 原始值/规范值 | `待填` |
| 计算路径、精度、稠密性、峰值/实测 | `待填` |
| $B_\text{HBM}$ 原始值/规范值、方向 | `待填` |
| 计算与单位换算 | `待填` |
| $R_{P/B}$ | `待填 FLOP/byte` |
| 可比性结论 | `comparable / not_comparable` |

### 13. 带宽相对算力

$$
R_{B/P}=\frac{B_\text{HBM}}{P_\text{peak}}
$$

单位为 byte/FLOP，与上一指标互为倒数。它不能与容量比混写。

### 14. HBM容量相对峰值算力

$$
R_{C/P}=\frac{C_\text{HBM}}{P_\text{peak}}
$$

这是本课题按用户要求保留的描述性比值，单位为 byte·s/FLOP（整数路径为 byte·s/OP）。现有固定语料和外部核验没有为它建立标准化诊断含义，三票核验中的C18也未确认其通用有效性。可以记录原始输入、计算过程和结果，但不得用它预测性能、判断模型能否装下，或单独判断芯片用途。

### 15. 模型或状态适配比

$$
F_\text{state}=\frac{C_\text{HBM}}{S_\text{state}}
$$

只有状态边界、对象层级、精度和运行条件明确时才分别计算；它是研究者定义的容量核算，不是标准性能指标：

| 状态分母 | 原始字节与作用域 | $C_\text{HBM}$ | $F_\text{state}$ | 解释 |
| --- | ---: | ---: | ---: | --- |
| 权重 |  |  |  | 大于1不等于有足够运行空间 |
| 训练状态合计 |  |  |  | 需包含激活、临时与通信预留 |
| 推理运行状态合计 |  |  |  | 需包含KV、并发与碎片预留 |

等于1只是名义装入边界；实际部署还要留出运行时、通信、分配器和可靠性余量。

## 交付前自检

- 对象是一个芯片或封装；卡、服务器、机架、集群和软件均标为外部对象。
- 原始值、规范值、单位、层级、精度、稠密性、峰值/实测、工作负载条件、定位和证据状态没有缺列。
- GB/GiB、单向/双向、线路/有效载荷、稠密/稀疏、理论/实测没有混用。
- 输入、乘积、累加、输出、主权重、梯度和优化器状态的精度没有互相代替。
- 训练与推理状态分别核算；KV cache包含序列、并发和分片条件。
- 每个派生指标保留输入、公式、换算和可比性判断。
- 结论能回到原文定位，并列出反例或不能覆盖的条件。
- `not_public`与`not_found`没有混用，未知值没有写成零。

模板到这里为止。填不出的字段本身就是研究结果：它说明公开披露不足，而不是允许用相邻型号、系统聚合值或常识补齐。
