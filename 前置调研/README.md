# 前置调研：训练与推理芯片架构关注点

本专题固定并逐篇审读19份公开资料，研究数据中心大语言模型（LLM）的训练、预填充和逐词解码；较早的深度神经网络（DNN）与卷积神经网络（CNN）资料只用于解释基础机制和时代边界。专题与项目正式事实库隔离，不修改32张正式数据表，也不替代`资料卡/模板.md`。

SKU 资料卡、共享架构资料和来源池位于兄弟目录 `../芯片调研/`。专题给出的分析维度可以用于设计逐 SKU 问题，但专题结论和固定语料不会自动成为某款产品的事实。

## 证据规则与核验结果

跨资料结论至少需要两个独立工作家族支持。S02和S06同属`WF-COLTRAIN`，不重复计票；同一厂商的多篇文章可以证明厂商表述一致，不能替代独立验证。报告把单一来源、厂商自述和主会话推导分别标成`单源观察`、`厂商设计意图`和`分析者推断`。

外部检索只用于核验固定语料形成的核心结论，不自动扩充S01至S19。三名核验者独立检查了20条候选结论，其中17条获得三票支持。C11片上存储、C13调度与服务质量、C18派生指标没有进入确认结论，只按证据边界保留为研究框架。没有结论触发“两票反驳”删除门。

## 验收与试填

19 张完整卡和 19 张摘要卡均通过当时的机器合同检查，证据矩阵可回到完整卡及固定原文。H100 和 Inferentia2 的[模板试填验收](../99_归档/01_前置调研旧过程/审计/模板试填验收.md)表明，高披露通用加速器与低披露推理芯片都能保留对象边界、冲突和缺失项。[派生指标复算](../99_归档/01_前置调研旧过程/审计/派生指标复算.csv)有 8 项数值通过，2 项互联指标因输入不足而明确不计算。

专题执行前后 32 张历史 CSV 表的路径、字节数和 SHA-256 逐项相同，见[正式数据未变更证明](../99_归档/01_前置调研旧过程/审计/正式数据未变更证明.md)。这些检查属于旧流程，不再作为 SKU 资料卡的完成条件。具体历史边界见[项目硬门检查](../99_归档/01_前置调研旧过程/审计/项目硬门检查.md)。

## 恢复与复核

专题内的语料处理、清单刷新和逐篇卡检查脚本都从脚本自身位置解析本目录，不依赖原机器的绝对路径。运行前先确认 Python 环境中有 `pypdf`；重新抽取 HTML 时还需要 `lxml`，生成 S05 联系表时需要 Pillow。

~~~text
python ../99_归档/01_前置调研旧过程/审计/刷新语料清单.py
python ../99_归档/01_前置调研旧过程/审计/固定语料处理脚本.py
python ../99_归档/01_前置调研旧过程/审计/检查逐篇卡.py
~~~

归档中的 `正式数据基线_执行前.csv` 和 `执行后.csv` 是 2026 年 8 月 14 日的历史证明，其中路径按当时的项目结构记录。文件只用于追溯，不再运行，也不改写。

## 访问边界

S09的官方原始HTML和PDF自动获取返回HTTP 403；本专题没有绕过访问控制，改用同一官方网页的可见文本快照，因此不能提供PDF版式与印刷页码核验。S16的TACO期刊全文入口也返回HTTP 403，按计划固定公开的arXiv`2104.02188v1`，报告只引用预印本页码。其他版本与访问说明见语料清单和各完整卡。
